# Glingo — Escola de Idiomas Online

> Projeto de conclusão da disciplina de **Laboratório de Desenvolvimento de Software**  
> Universidade UNIJORGE

---

## Sobre o Projeto

O **Glingo** é um sistema web completo desenvolvido para modernizar o processo de gestão de uma escola de idiomas. A aplicação permite o cadastro de alunos, gerenciamento de turmas, realização de matrículas e atendimento via mensagens — tudo integrado em uma interface web amigável e responsiva.

---

## Funcionalidades

-  **Cadastro e login de alunos**
-  **Catálogo de turmas** com filtros por idioma e nível
-  **Sistema de matrícula** com controle de vagas em tempo real
-  **Sistema de atendimento** com troca de mensagens por IA
-  **Painel administrativo** com métricas e gerenciamento
-  Idiomas disponíveis: **Inglês, Espanhol, Português e Mandarim**
